# RZXXY DEV - Server Performance Stats

A shell-based server monitoring project.

## Features

- Operating System Detection
- Memory Information Detection
- Disk Usage Detection
- CPU Information Detection
- Top 5 Processes by CPU
- Top 5 Processes by Memory

## Requirements

- POSIX-compatible shell
- Linux system for server metrics

## Run

sh server-stats.sh

## Development Environment

Created using an iPhone with a-Shell.
